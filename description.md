## Problem Background

There's a big churn on February after the 'new year new me' subscribers trend in January. Although it's an inevitable trend in the gym business, how can we keep the members we got in January and reduce the churn when February comes?

## Project Output
The output of this project focuses on the descriptive and inferential statistical analysis of the data. By defining the specific goals and main problems first before doing the analysis and intepretation of the results. Suggestions and solutions are also being included in the notebook. 

The results then being translated into a Tableau Dashboard to see the diagrams being visualized in the notebook before. A brief explanation is also included in Bahasa Indonesia.

## Data
The dataset we use for this analysis is by Sergey Nefedov from Kaggle.com. Please find the link of the dataset source below: 
https://www.kaggle.com/datasets/sergionefedov/gym-will-your-new-years-resolution-survive/data

This dataset contains a total of 50000 rows and 24 columns. This dataset source doesn't contain missing values and the boolean data is set to 0 and 1 that needs to be updated with string for better data visualization. This data contains identification and behaviour of the members. Identification columns are Member ID, Gender, Age, distance, contract type, and fee, while behaviour columns are total visits, duration per session, booked personal trainer, booked induction, weekly classes, etc.
